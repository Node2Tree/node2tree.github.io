# 冷色系放映室：本地影片供片

主机入口：https://node2tree.github.io/p2p/

## 开一场放映

1. 在电脑的 Chrome 或 Edge 中打开主机入口，点击「选择本地影片」。
2. 确认影片能播放、时长正确；按需修改片名。
3. 点击「创建放映室」，将生成的观众链接发给朋友。
4. 点击「开始放映」。主机可以暂停、继续、拖动进度，观众会跟随。
5. 朋友打开链接；若浏览器没有自动播放，点击「点击播放 · 跟随主机」。
6. 点击「全屏」可让画面、片名、已播放／总时长一起进入全屏；播放器也有原生全屏和音量控件。
7. 结束时点击「结束房间」。再次开场时创建新房间并重新分享链接。

影片不上传到 R2 或其他云盘。只读取你明确选择的本地文件。保持主机页面打开、电脑联网并避免休眠。手机浏览器的后台限制更严，供片端建议使用电脑。

## 连接与影片格式

- 默认用 PeerJS 公共服务建立连接；影片数据通过 WebRTC 直接传输。当前版本由主机分别向观众供片，最多八名观众，没有观众之间的分片转发。
- 校园网、移动网络或严格的 NAT 可能无法直连。双方可在「连接设置」中配置自己有权使用的 TURN 中继；主机需要重新创建房间，观众需要重新连接。TURN 密码仅保留在页面内存，不保存到浏览器存储或分享链接。此版本未提供内置 TURN 账户。
- 支持浏览器本身能播放的影片格式，推荐 H.264 视频 + AAC 音频的 MP4。不是任意 MKV、HEVC 或字幕格式都能播放；当前没有自动转码或外置字幕加载。
- 使用随机房间密钥校验观众，分享链接本身就是入场凭证。主机退出后链接失效。第三方公共连接服务的可用性不由本站保证。
- 标准 MP4 由浏览器按需请求文件头、尾和播放位置对应的字节范围，经 WebRTC 传输；不需为了传输先把整部影片读入内存，也不需要预先上传。

## 源码与验证

静态入口 `index.html`，应用 `app.js`，范围请求桥接 `sw.js`，共享协议 `protocol.js`。PeerJS 1.5.5 固定版本随站点保存，MIT 许可在 `vendor/PEERJS-LICENSE` 中。

本机使用合成的两分钟 MP4 验证了实际分片传输、迟到加入、主机播放／暂停／跳转、片名和时长显示、全屏，以及结束房间。协议测试验证字节范围、非法请求、分片上限、取消和不缓存影片。

本机测试无法证明朋友所在网络能直连，也不能代替多设备试播。正式放映前请让一位朋友用实际网络加入，播放几分钟并测试暂停／恢复。
